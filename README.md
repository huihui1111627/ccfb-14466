# EONSA — 弹性光网络路由与频谱分配仿真系统

面向省干线传输网的弹性光网络（EON）规划工具：在细粒度频隙网格上完成
路由与频谱分配（RSA）、电中继规划、碎片度量、不中断碎片整理和扩容诊断，
并通过 Web 页面展示拓扑、频谱占用条和整理挪动动画。

## 核心建模

| 主题 | 实现 |
|------|------|
| 频隙网格 | 每段光纤 320 个 12.5GHz 频隙（可调），相邻连接保留 1 个保护带；保护带不登记归属，通过区间外扩动态判定，释放时无归属歧义 |
| 连续性 + 一致性 | 一条中继段在沿途每段光纤占用 `[start, start+slots)` 的连续频隙，且所有链路上 `start` 完全相同，中途不换位置 |
| 调制自适应 | 16QAM/8QAM/QPSK/BPSK，按段长选最高阶调制；距离越远效率越低、占频隙越多；超过 BPSK 极限（4000km）必须加电中继 |
| 中继权衡 | 路径上动态规划求中继位置，代价 = 各段频隙数 + 中继数 × 权重（默认一个中继折算 8 频隙），中继可在换段时换频谱位置 |
| 路由 | Yen k 最短路径（默认 5 条候选），每条路径独立评估中继与频谱可行性后再择优 |
| 放置策略 | 首次适配 first-fit、最后适配 last-fit、碎片影响最小 frag-aware（临时试放，取外部碎片率增量最小的位置） |

## 碎片指标

外部碎片率（External Fragmentation）：

```
EF = 1 − 最大连续空闲块 / 总空闲频隙数
```

- 空闲总量充足但被切碎、最大块很小时 EF 趋近 1，直接刻画
  "总空闲还有三成、大通道却开不出来"的现象；
- 辅助指标：空闲块大小分布的归一化香农熵，以及大通道阻塞潜力
  （最大空闲块低于全网中位数的链路占比）。

## 不中断碎片整理

推挽式（push-pull）无损重调，约束严格落地：

1. 业务全程不断：中继段整体在沿途链路上同步移动，不释放再重建；
2. 只能沿频隙编号减小方向（向左）逐 slot 推；
3. 不能跳过其他通道：目标位置由所有链路公共可行起点交集确定；
4. 全局守卫：每次试移动后比较全网平均碎片率，恶化则撤销跳过，
   整理只执行净收益为正的挪动；
5. 无死锁：每个动作严格减小起始频隙、有下界 0，轮次必然终止，
   且段只向左移动不会形成互相等待的环。

输出挪动顺序表与预计耗时（每 slot 重调 2s + 每次准备 3s，可调）。

## 扩容诊断

业务阻塞时记录每条候选路径上最紧张的链路（最大空闲块最小者）的命中次数，
然后做反事实试算：在**仿真终态网络的副本**上给某链路扩容 32 个频隙，
重放全部历史阻塞请求，统计能被挽回的请求数——优先扩容挽回数最大的光纤段。

## 目录结构

```
cmd/eonsa            CLI 入口（sim / bottleneck / demo-defrag / serve）
internal/model       拓扑、频隙网格、调制表、连接与中继段
internal/routing     Dijkstra + Yen k 最短路径
internal/rsa         中继分段 DP、三种放置策略、碎片指标、瓶颈分析
internal/defrag      不中断左压缩整理、挪动计划与耗时
internal/topogen     三角剖分 + 割点补齐的双连通干线拓扑
internal/sim         多年业务事件流、6 组场景对比、月度统计
internal/webapi      HTTP 接口与嵌入的单页面前端
```

## 快速开始

```bash
# 跑 3 年、36 节点、6 组场景对比（3 策略 × 是否整理）
go run ./cmd/eonsa sim

# 瓶颈链路与扩容收益
go run ./cmd/eonsa bottleneck -top 8

# 小规模手工碎片场景的整理演示
go run ./cmd/eonsa demo-defrag

# 启动 Web 平台（默认 :8080）
go run ./cmd/eonsa serve
# 浏览器打开 http://localhost:8080
```

常用参数（所有子命令通用）：`-nodes`、`-slots`、`-months`、`-seed`、`-out`。

## Web 页面

- **网络与频谱**：SVG 拓扑（点节点选源/宿、点链路高亮频谱）、
  每段光纤的频谱占用条（颜色区分连接、灰色保护带、悬停看连接详情）、
  交互式开通/拆除业务；
- **场景对比**：阻塞率、利用率、碎片率、中继数随月份变化的 6 条曲线；
- **碎片整理**：逐动作播放频谱挪动动画，附挪动顺序与耗时明细表；
- **瓶颈诊断**：扩容收益排名表。

## 默认仿真设置与典型结果

36 节点双连通拓扑、每链路 320 频隙、3 年（36 个月）业务流，
首月 6 条请求、年增 15%、平均持有 12 个月，速率档
100G/200G/400G/800G。终态利用率约 33%~40%（空闲充足），
碎片整理可把 first-fit 阻塞率相对降低约 1/4，frag-aware
策略本身阻塞率最低。所有 6 个场景重放同一条事件流，结果严格可比。
